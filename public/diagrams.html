คำอธิบายหลัก:

  • พยาบาลรุ่นน้อง: ใช้บันทึกเสียงส่งเวร ➡️ ดูการ์ด SBAR ➡️ ดูคำถามดักคอ (Cheat Sheet) ➡️ ส่งข้อมูลให้เพื่อน ➡️ อ่านเกร็ดความรู้และเล่นควิซ

🔄 แผนภาพลำดับขั้นตอน (Sequence Diagram)

ขั้นตอนการทำงานหลักของระบบ The Nurse Note

กระบวนการเข้าสู่ระบบเครื่องส่วนตัว (BYOD) & ปลดล็อก Quick PIN:

sequenceDiagram
    autonumber
    actor Nurse as 👩‍⚕️ พยาบาลผู้ใช้งาน
    participant UI as 📱 Auth & Login UI (เครื่องส่วนตัว)
    participant Gateway as 🌐 API Gateway & RBAC
    participant AuthSvc as 🔑 Identity & Device Service
    participant DB as 💾 User DB

    Nurse->>UI: 1. ป้อน Email / Staff ID + Password
    UI->>Gateway: 2. ส่งรหัสผ่าน + Device Fingerprint เฉพาะเครื่อง
    Gateway->>AuthSvc: 3. ตรวจสอบรหัสผ่าน & ตรวจสอบการผูกเครื่อง (Device Binding)
    AuthSvc->>DB: 4. ดึงข้อมูลผู้ใช้ + boundDeviceId
    DB-->>AuthSvc: 5. ข้อมูลผู้ใช้และรหัส Hash
    alt เครื่องตรงกับที่ลงทะเบียนไว้ (Personal Device Match)
        AuthSvc-->>Gateway: 6. สิทธิ์ถูกต้อง ออก Bound JWT Token
        Gateway-->>UI: 7. ล็อกอินสำเร็จ เข้าสู่หน้าเตียง & จัดเวร
    else อุปกรณ์อื่นพยายามล็อกอิน
        AuthSvc-->>Gateway: 8. แจ้งเตือนย้ายเครื่อง (Single Active Device Policy)
    end
    Note over Nurse, UI: เมื่อสลับหน้าจอหรือวางเครื่องระหว่างเวร
    Nurse->>UI: 9. ปลดล็อกด่วนด้วย Quick PIN 4 หลักเฉพาะเครื่องตนเอง
    UI-->>Nurse: 10. ปลดล็อกทันที ทำงานหน้าเตียงต่อเนื่อง

ขั้นตอนการอัดเสียงส่งเวร ➡️ กรองข้อมูลตาม PDPA ➡️ แปลงเป็น SBAR + ดักคำถามรุ่นพี่:

sequenceDiagram
    autonumber
    actor Nurse as 👩‍⚕️ พยาบาลรุ่นน้อง
    participant UI as 📱 แอป The Nurse Note
    participant Filter as 🛡️ ตัวกรอง PDPA
    participant AudioAPI as 🤖 Gemini Audio (STT)
    participant LLM as 🤖 Gemini SBAR & CheatSheet
    participant DB as 💾 บันทึกส่งเวร

    Nurse->>UI: 1. แตะไมค์ พูดเล่าอาการคนไข้
    Nurse->>UI: 2. แตะหยุดบันทึก
    UI->>AudioAPI: 3. ส่งเสียงแปลงเป็นข้อความ (Speech to Text)
    AudioAPI-->>UI: 4. ส่งข้อความดิบกลับมา
    UI->>Filter: 5. ตรวจจับ & ลบชื่อจริง/HN ออก
    Filter->>LLM: 6. ส่งข้อความ Cleaned Text เข้า AI
    LLM-->>UI: 7. สรุปเป็น SBAR + คำถามที่รุ่นพี่มักจะถามจี้
    UI->>DB: 8. บันทึกลงระบบ
    UI-->>Nurse: 9. แสดงผลบนหน้าจอ น้องอ่านซ้อมส่งเวรได้เลย!

🧱 แผนภาพคลาส (Class Diagram)

classDiagram
    class User {
        +String userId
        +String staffId
        +String email
        +String fullName
        +String nickname
        +Role role
        +String boundDeviceId
        +String pinHash
        +String passwordHash
        +Int expPoints
        +Int level
    }

    class Bed {
        +String bedId
        +String bedNumber
        +String age
        +String gender
        +String primaryDiagnosis
        +AcuityLevel acuityLevel
        +List activeLines
        +List highAlertDrugs
    }

    class HandoverNote {
        +String noteId
        +String bedId
        +DateTime handoverTime
        +String situation
        +String background
        +String assessment
        +String recommendation
        +List preceptorQuestions
    }

    class SeniorPearl {
        +String pearlId
        +String authorName
        +String title
        +String content
        +Int heartCount
    }

    class QuizQuestion {
        +String questionId
        +String questionText
        +List choices
        +Int correctIndex
        +String rationale
        +Int expReward
    }

    User "1" --> "*" HandoverNote : สร้างโน้ตส่งเวร
